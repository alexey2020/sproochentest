# Telegram-бот для подготовки к Sproochentest

Работает на том же материале и по тем же правилам плана, что и веб-тренажёр (`index.html`): личный план по неделям до даты экзамена, темы устной части, курс RTL Today, карточки с транскрипцией, описание фото, квиз и грамматика.

При первом запуске бот спрашивает дату экзамена (или «свой темп»), уровень и минуты в день. Профиль и отметки хранятся в той же базе синхронизации, что и у сайта: у каждого пользователя бота свой код синхронизации (⚙️ Настройки → Код и сайт). Его можно ввести на сайте, или наоборот подключить в боте код с сайта, и прогресс станет общим.

## Файлы

- `bot.py` — команды и кнопки
- `plan.py` — расписание и слияние прогресса, перенесены из `index.html` один в один
- `store.py` — чтение и запись прогресса в базу синхронизации сайта
- `data.json` — материал и правила плана, выгружаются из `index.html`

## Команды

| Команда | Что делает |
|---|---|
| `/start`, `/menu` | Главное меню |
| `/today` | Неделя плана, задачи с отметками, отметка дня занятий |
| `/plan` | Все недели плана |
| `/settings` | Дата экзамена, уровень, минуты в день, начать заново, код синхронизации |
| `/cards` | Карточки: русский → люксембургский, потом ответ с транскрипцией |
| `/sim` | Вопрос экзаменатора, подсказки и уточняющие вопросы |
| `/photo` | Сцена для описания и шаблон ответа |
| `/quiz` | Квиз по грамматике с объяснениями |
| `/rtl` | Курс RTL Today: по неделям плана или по разделам, ссылки открывают уроки на сайте RTL, пройденное можно отмечать |
| `/grammar`, `/topics`, `/rescue` | Справочник |

## Запуск на своём компьютере

```bash
cd bot
pip install -r requirements.txt
BOT_TOKEN=123456:ABC... BOT_SECRET=любая-длинная-строка python bot.py
```

Без `WEBHOOK_URL` бот работает в режиме long polling, сервер не нужен.

## Хостинг на Render (бесплатно)

1. [render.com](https://render.com) → войти через GitHub.
2. **New → Blueprint** → выбрать репозиторий `sproochentest` (Render найдёт `render.yaml`).
3. На вопрос о `BOT_TOKEN` вставить токен от @BotFather → **Apply**. `BOT_SECRET` Render сгенерирует сам.

`BOT_SECRET` нельзя менять после того, как ботом начали пользоваться: из него получаются коды синхронизации пользователей.

Render сам задаёт `RENDER_EXTERNAL_URL`, и бот переключается на webhook. На бесплатном тарифе сервис засыпает после 15 минут без запросов; первое сообщение после паузы будит его примерно за 30–60 секунд, дальше бот отвечает сразу.

## Обновление материала

После правок в `index.html`:

```bash
node bot/tools/extract_data.js   # пересоздаёт bot/data.json
```
